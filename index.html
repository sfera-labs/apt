Sfera Labs apt repository

Install DKMS packages for Sfera Labs products on Raspberry Pi OS.

Bootstrap the repository

curl -fLO https://apt.sferalabs.cc/bootstrap/sferalabs-archive-keyring_all.deb
sudo apt install ./sferalabs-archive-keyring_all.deb
sudo apt update

Then install your product package, for example sudo apt install stratopimax-dkms.

See the product documentation for installation and migration instructions.
